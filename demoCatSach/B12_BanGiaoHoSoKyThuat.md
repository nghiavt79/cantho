# BƯỚC 12 — Bàn giao Hồ sơ Kỹ thuật
**Đăng nhập bằng:** Bên bán (`catsachmekong`)

| Field | Giá trị |
|---|---|
| Đã bàn giao đầy đủ | ✔ (tick / bật) |
| Ngày bàn giao | *(chọn ngày hôm nay)* |

**Danh mục hồ sơ:**
```
- Bản vẽ thiết kế hệ thống tuyển rửa.
- Quy trình công nghệ tuyển rửa và khử mặn.
- Tài liệu vận hành – bảo trì thiết bị.
- Hồ sơ kiểm định chất lượng cát thành phẩm.
```

**Ghi chú:**
```
Đã bàn giao đầy đủ cả bản in và bản mềm cho bên nhận.
```

**Các file đính kèm** `[TẢI FILE]`:
- Tài liệu kỹ thuật / Hướng dẫn vận hành / Bảo trì → **`uploads/B12_TaiLieuKyThuat_HuongDanVanHanh.pdf`** (đã gộp, tạo sẵn).
- Source code / Database: bỏ trống (không áp dụng cho hệ thống cơ khí này).
